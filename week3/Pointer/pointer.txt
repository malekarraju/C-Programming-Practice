**************** Pointers in C (Complete Guide) ****************

Pointers are one of the most important concepts in C programming.

They are especially important in Embedded C because they are used for memory access, arrays, structures, functions, and hardware registers.


---

Definition

A pointer is a variable that stores the memory address of another variable.

Example:

int a = 10;
int *p = &a;

Here:

a  → stores 10
p  → stores address of a
*p → gives value stored at that address


---

Why Do We Need Pointers?

Suppose you want a function to modify the original variable.

Without pointer:

void change(int x)
{
    x = 20;
}

The original variable is not changed.

Using pointer:

void change(int *x)
{
    *x = 20;
}

Now the original variable can be modified.

Pointers are also required for:

Dynamic memory allocation

Arrays

Strings

Structures

Function arguments

Function pointers

Memory-mapped registers

Embedded hardware programming



---

Pointer Syntax

data_type *pointer_name;

Example:

int *p;
float *f;
char *c;
double *d;

The pointer type indicates the type of data it is intended to point to.


---

Important Pointer Operators

There are two main operators associated with basic pointers.

1. Address Operator &

The & operator gives the address of a variable.

int a = 10;

printf("%p", (void *)&a);

&a means:

Address of a


---

2. Dereference Operator *

The * operator is used to access the value stored at the address contained in a pointer.

int a = 10;
int *p = &a;

printf("%d", *p);

Output:

10


---

Basic Pointer Example

#include <stdio.h>

int main()
{
    int a = 10;
    int *p = &a;

    printf("Value of a = %d\n", a);
    printf("Address of a = %p\n", (void *)&a);
    printf("Value of p = %p\n", (void *)p);
    printf("Value using pointer = %d\n", *p);

    return 0;
}


---

Relationship Between Variable and Pointer

int a = 10;
int *p = &a;

Conceptually:

a
+------+
|  10  |
+------+
   ↑
   |
   | address of a
   |
p
+----------------+
| address of a   |
+----------------+

Therefore:

a   → value of a
&a  → address of a
p   → address stored in p
*p  → value at the address stored in p


---

Pointer Initialization

A pointer should be initialized before using it.

int a = 10;
int *p = &a;

Here:

p → address of a
*p → 10


---

Changing Value Using Pointer

A pointer can be used to modify the original variable.

int a = 10;
int *p = &a;

*p = 50;

printf("%d", a);

Output:

50

Because p points to a, changing *p changes a.


---

NULL Pointer

A NULL pointer does not point to a valid object.

int *p = NULL;

Before dereferencing a pointer that may be NULL:

if (p != NULL)
{
    printf("%d", *p);
}

Never do:

int *p = NULL;

printf("%d", *p);

This results in undefined behavior.


---

Wild Pointer

A pointer that has not been initialized is called a wild pointer.

int *p;

p contains an indeterminate value.

Using it can cause undefined behavior.

Better:

int *p = NULL;


---

Dangling Pointer

A dangling pointer is a pointer that refers to memory that is no longer valid.

Example:

int *p = malloc(sizeof(int));

free(p);

After free(p), p should not be dereferenced.

Better:

free(p);
p = NULL;


---

Pointer and Array

Pointers and arrays are closely related.

Example:

int arr[3] = {10, 20, 30};

int *p = arr;

Here:

p       → address of arr[0]
*p      → 10
*(p+1)  → 20
*(p+2)  → 30

These are equivalent:

arr[0]      → *p
arr[1]      → *(p + 1)
arr[2]      → *(p + 2)


---

Pointer Arithmetic

Pointer arithmetic allows us to move between elements.

int arr[3] = {10, 20, 30};
int *p = arr;

printf("%d\n", *p);
printf("%d\n", *(p + 1));
printf("%d\n", *(p + 2));

Output:

10
20
30

Common operations:

p + 1
p - 1
p++
p--

The pointer moves according to the size of its data type.

For example, if int occupies 4 bytes:

p       → address 1000
p + 1   → address 1004
p + 2   → address 1008


---

Pointer and String

A character pointer can point to a string.

char *p = "Hello";

Here:

p    → address of 'H'
*p   → 'H'

You can also use:

char name[] = "RAJU";
char *p = name;


---

Pointer to Pointer

A pointer can store the address of another pointer.

int a = 10;

int *p = &a;

int **q = &p;

Relationship:

a  → 10

p  → address of a

q  → address of p

Therefore:

*p   → 10
*q   → address stored in p
**q  → 10


---

Pointer and Function

Pointers allow functions to modify the original variable.

Example:

void change(int *p)
{
    *p = 100;
}

int main()
{
    int a = 10;

    change(&a);

    printf("%d", a);

    return 0;
}

Output:

100

Here:

&a → address of a
p  → receives address of a
*p → modifies a


---

Call by Value

void change(int x)
{
    x = 100;
}

The function receives a copy.

Therefore, the original variable is not changed.


---

Using Pointer to Modify Original Value

void change(int *x)
{
    *x = 100;
}

Calling:

change(&a);

The original variable can be modified.


---

Pointer and Structure

Pointers can point to structures.

struct Student
{
    int age;
};

struct Student s = {20};

struct Student *p = &s;

Access member using:

p->age

This is equivalent to:

(*p).age

The -> operator is commonly used with structure pointers.


---

Pointer and Dynamic Memory

Pointers are used with dynamic memory allocation.

Functions include:

malloc()
calloc()
realloc()
free()

Example:

int *p;

p = malloc(5 * sizeof(int));

Here, p stores the address of dynamically allocated memory.

After use:

free(p);
p = NULL;


---

Void Pointer

A void * is a generic pointer.

void *p;

It can store the address of different object types.

Example:

int a = 10;

void *p = &a;

Before accessing the value, use the appropriate type.

printf("%d", *(int *)p);


---

Function Pointer

A pointer can store the address of a function.

Example:

int add(int a, int b)
{
    return a + b;
}

int (*p)(int, int) = add;

Now the function can be called using:

printf("%d", p(10, 20));

Function pointers are useful for:

Callbacks

Interrupt-related programming

Drivers

State machines

Embedded systems



---

Pointer and const

const can be used with pointers in different ways.

Example:

const int *p;

The value pointed to cannot be modified through p.

Another:

int *const p = &a;

The pointer itself cannot point somewhere else.

Both can be combined:

const int *const p = &a;

Neither the pointer nor the pointed value can be modified through p.


---

Pointer and volatile in Embedded C

volatile is very important in Embedded C.

Example:

volatile int *p;

It tells the compiler that the value can change unexpectedly, such as because of:

Hardware registers

Interrupts

Peripheral hardware

Shared memory


Example:

volatile unsigned int *reg =
    (volatile unsigned int *)0x40000000;

This type of pointer can be used for memory-mapped hardware registers.


---

Pointer in Embedded Systems

Pointers are extremely important in Embedded C.

Common uses:

Accessing hardware registers

GPIO control

UART communication

SPI communication

I2C communication

CAN communication

ADC/DAC registers

Timers

Interrupt handling

Buffers

Arrays

Structures

Device drivers

Memory management


Example:

volatile unsigned int *GPIO_REG =
    (volatile unsigned int *)0x40000000;

*GPIO_REG = 1;

Conceptually:

GPIO_REG → hardware register address
*GPIO_REG → value inside that register


---

Pointer Size

The size of a pointer depends mainly on the target architecture.

Common examples:

32-bit system → commonly 4 bytes
64-bit system → commonly 8 bytes

Do not assume every pointer is always 4 or 8 bytes; the C standard does not impose those exact sizes.


---

Pointer vs Normal Variable

Normal Variable	Pointer

Stores a value	Stores an address
Example: int a	Example: int *p
Access value directly	Access value using *
a gives value	p gives stored address
&a gives address	*p gives pointed value



---

Pointer vs Array

Pointer	Array

A variable that stores an address	Collection of elements
Can be reassigned	Array name cannot be reassigned
Supports pointer arithmetic	Supports indexing
Can point to different objects	Represents its own storage
sizeof(p) gives pointer size	sizeof(arr) gives total array size when arr is an actual array



---

Common Pointer Mistakes

1. Uninitialized Pointer

int *p;
*p = 10;

Wrong because p has not been initialized.


---

2. NULL Pointer Dereference

int *p = NULL;

*p = 10;

Wrong because p does not point to a valid object.


---

3. Dangling Pointer

int *p = malloc(sizeof(int));

free(p);

*p = 10;

Wrong because the allocated memory has already been released.


---

4. Accessing Outside an Array

int arr[5];

arr[10] = 20;

This results in undefined behavior.


---

5. Wrong Pointer Type

float a = 10.5;
int *p = &a;

This is an incompatible pointer type and should not be used this way.


---

Advantages of Pointers

Direct memory access.

Efficient function parameter passing.

Can modify original variables.

Useful with arrays and strings.

Required for dynamic memory allocation.

Useful for structures.

Supports function pointers.

Essential for many embedded-system applications.

Allows access to memory-mapped hardware registers.



---

Disadvantages of Pointers

Can be difficult for beginners.

Incorrect use can cause crashes.

Can create memory-related bugs.

Dangling pointers can occur.

NULL pointer dereferencing can cause undefined behavior.

Pointer arithmetic can cause out-of-bounds access.

Makes debugging more difficult when used incorrectly.
